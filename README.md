# Lammah bite

موقع Lammah bite — عربة بانكيك وضيافة مناسبات في المدينة المنورة.

## نشر الموقع على GitHub Pages

1. ادفع (push) جميع الملفات إلى الفرع الرئيسي main في هذا المستودع.
2. اذهب إلى تبويب Settings في المستودع على GitHub.
3. من القائمة الجانبية اختر Pages.
4. تحت Build and deployment، اختر Source: Deploy from a branch.
5. اختر Branch: main والمجلد: / (root).
6. اضغط Save، وانتظر بضع دقائق حتى يصبح الموقع متاحاً على:
   https://raedalsubhi2548.github.io/bankeek/
